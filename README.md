# Gossip Folks

Gossip Folks is a lighthearted, illustrated quiz that reveals your gossip type. Answer 21 questions about your motives, discretion, and role in gossip, then see your matching type and a breakdown of your scores.

## Run locally

No build step or dependencies are required. Clone the repository, then either open `index.html` in a browser or serve the project directory locally:

```sh
python3 -m http.server 8000
```

Visit [http://localhost:8000](http://localhost:8000) to take the quiz.

## Gossip types

- The Protector
- The Confidant
- The Auntie
- The Observer
- The Spiller
- The Lurker
- The TV/Radio Host
- The Spectator

## Project files

- `index.html` contains the quiz and result markup.
- `styles.css` contains the page styling.
- `app.js` scores quiz answers and displays the result.
- PNG files provide the icons and illustrated type portraits.
